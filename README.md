# TicketGen — лабораторная работа №1

Консольное Java-приложение для регистрации студентов и генерации экзаменационных
билетов. Программа запрашивает фамилию и имя, генерирует номер билета от 1 до 20 и
сразу сохраняет запись в `journal.xlsx`.

## Технологии и требования

- Java 17;
- Apache Maven 3.9 или новее;
- Apache POI 5.5.1 для работы с `.xlsx`;
- JLine 4.4.6 с JNI-провайдером для посимвольного ввода в Windows-консоли;
- JUnit 5 для автоматических тестов.

## Архитектура

- `Main` — создаёт зависимости и запускает приложение.
- `TicketApplication` — управляет последовательностью действий и основным циклом.
- `ConsoleInput` — читает клавиши, обрабатывает Enter, Backspace и ESC.
- `NameValidator` — удаляет пробелы через `trim()` и отклоняет пустые значения.
- `TicketGenerator` — генерирует номер билета в диапазоне 1–20 включительно.
- `StudentRecord` — неизменяемая модель одной записи журнала.
- `JournalRepository` — абстракция хранилища, позволяющая заменить Excel другой
  реализацией без изменения основного цикла.
- `ExcelJournalRepository` — создаёт, открывает и сохраняет `journal.xlsx` через
  Apache POI.

## Сборка и тестирование

```powershell
mvn clean package
```

Команда выполняет unit-тесты и создаёт исполняемый файл `target/ticketgen.jar`.
Для отдельного запуска тестов:

```powershell
mvn test
```

## Запуск

Запускайте приложение из корня проекта в обычном интерактивном терминале Windows:

```powershell
java -jar target/ticketgen.jar
```

Файл `journal.xlsx` создаётся в текущей рабочей директории.

## Формат журнала

Первая строка содержит заголовки:

| A | B | C | D |
|---|---|---|---|
| Last name | First name | Номер билета | Дата и время |

Дата и время сохраняются в формате `dd.MM.yyyy HH:mm:ss`. Каждая новая запись
добавляется после последней существующей строки; старые строки не изменяются.

## Обработка ESC

Стандартный `Scanner.nextLine()` требует нажатия Enter и поэтому не подходит для
мгновенного выхода. `ConsoleInput` использует JLine с нативным JNI-провайдером:
терминал переводится в посимвольный режим, и код клавиши ESC (`27`) распознаётся
сразу. Enter подтверждает строку, Backspace удаляет последний символ. При закрытии
приложения исходный режим терминала восстанавливается.

## Надёжное сохранение

После ввода одного студента `ExcelJournalRepository` открывает существующий журнал
или создаёт новый, добавляет строку и записывает книгу во временный файл. Данные
принудительно сбрасываются на диск, после чего временный файл атомарно заменяет
`journal.xlsx`. Только после успешного сохранения программа выводит номер билета.
Поэтому уже подтверждённая запись остаётся в файле даже при последующем аварийном
завершении приложения.

Если `journal.xlsx` открыт в Microsoft Excel и Windows запрещает его замену,
ошибки доступа и ввода-вывода перехватываются. Программа не выводит stack trace,
а просит закрыть файл и повторить ввод; существующий журнал при этом не
перезаписывается и не удаляется.
